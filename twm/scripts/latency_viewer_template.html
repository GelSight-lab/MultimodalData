Tactile Latency Scope

Frame-accurate inspection of GelSight deformation lag vs. visual contact. All streams are frame-aligned from the source recording, so any observed lag is real acquisition latency. 10 s clips @ 30 fps, 1× real-time.

▸ How to measure the lag

  1. Pick a clip, hit Space to play it once, then pause near the contact event.
  2. Step with ← / → (1 frame = 1/30 s). Find frame A = the camera row shows the sensor visually touching the object.
  3. Keep stepping to frame B = the GelSight diff cell (row 2) lights up with deformation.
  4. Latency = (B − A) / 30 seconds. The frame counter is top-left of each panel and in the readout.
Source: yxma/React · Panel: row 1 = 3× RealSense + OptiTrack · row 2 = GelSight L/R raw + diff · Clips re-encoded to yuv420p for browser playback.
